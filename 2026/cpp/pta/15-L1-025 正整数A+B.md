# L1-025 正整数A+B (**分数 15**)

### 题目描述

题目的目标很简单，就是求两个正整数 A 和 B 的和，其中 A 和 B 都在区间 [1, 1000]。稍微有点麻烦的是，输入并不保证是两个正整数。

### 输入格式：

输入在一行给出 A 和 B，其间以空格分开。问题是 A 和 B 不一定是满足要求的正整数，有时候可能是超出范围的数字、负数、带小数点的实数、甚至是一堆乱码。

注意：我们把输入中出现的第 1 个空格认为是 A 和 B 的分隔。题目保证至少存在一个空格，并且 B 不是一个空字符串。

### 输出格式：

如果输入确实是两个正整数，则按格式 `A + B = 和` 输出。如果某个输入不合要求，则在相应位置输出 `?`，显然此时和也是 `?`。

### 输入样例 1:
```text
123 456
```
### 输出样例 1:
```text
123 + 456 = 579
```
### 输入样例 2:
```text
22. 18
```
### 输出样例 2:
```text
? + 18 = ?
```
### 输入样例 3:
```text
-100 blabla bla...33
```
### 输出样例 3:
```text
? + ? = ?
```

## Code
```c
#include<iostream>
#include<string>
#include<cctype>
#include<numeric>
using namespace std;

bool Judge_vaild(string n){
    bool vaild = true;
    for(char c : n){
        if(!isdigit(c)){
            vaild = false;
            break;
        }
    }
    if(vaild){
        if(stoi(n)<1||stoi(n)>1000){
            vaild = false;
        }
    }
    return vaild;
}

int main(){

    string line,a,b;
    getline(cin,line);
    //分离a,b
    size_t pos = line.find(' ');
    a = line.substr(0,pos);
    b = line.substr(pos+1);
    
    bool vaild_a = Judge_vaild(a);
    bool vaild_b = Judge_vaild(b);

    cout<<(vaild_a?a:"?")<<" + "<<(vaild_b?b:"?")<<" = ";
    if(vaild_a&&vaild_b){
        cout<<stoi(a)+stoi(b)<<endl;
    }else{
        cout<<"?"<<endl;
    }

    return 0;
}
```
