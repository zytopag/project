# L1-030 一帮一 (**分数 15**)

### 题目描述

“一帮一学习小组”是中小学中常见的学习组织方式，老师把学习成绩靠前的学生跟学习成绩靠后的学生排在一组。本题就请你编写程序帮助老师自动完成这个分配工作，即在得到全班学生的排名后，在当前尚未分组的学生中，将名次最靠前的学生与名次最靠后的异性学生分为一组。

### 输入格式：

输入第一行给出正偶数 N (&le; 50)，即全班学生的人数。此后 N 行，按照名次从高到低的顺序给出每个学生的性别（0 代表女生，1 代表男生）和姓名（不超过 8 个英文字母的非空字符串），其间以 1 个空格分隔。这里保证本班男女比例是 1:1，并且没有并列名次。

### 输出格式：

每行输出一组两个学生的姓名，其间以 1 个空格分隔。名次高的学生在前，名次低的学生在后。小组的输出顺序按照前面学生的名次从高到低排列。

### 输入样例 1:
```text
8
0 Amy
1 Tom
1 Bill
0 Cindy
0 Maya
1 John
1 Jack
0 Linda
```
### 输出样例 1:
```text
Amy Jack
Tom Linda
Bill Maya
Cindy John
```

## Code
```c
#include<iostream>
#include<string>
#include<vector>
using namespace std;

int main(){

    int n;
    cin>>n;

    vector<string>female;
    vector<string>male;
    int sex[n] = {0};
    for(int i = 0;i < n;i++){
        string name;
        cin>>sex[i]>>name;

        if(sex[i] == 0){
            female.push_back(name);
        }else{
            male.push_back(name);
        }
    }
    /*调试
    for(int val : sex){
        cout<<val<<" ";
    }
    cout<<endl;
    for(int i = 0;i<n/2;i++){
        cout<<male[i]<<" "<<female[i]<<endl;
    }
    cout<<endl;
    */
    int j = 0,k = 0;
    for(int i = 0;i < n/2;i++){
        if(sex[i] == 0){
            cout<<female[j]<<" "<<male[n/2 - 1 - j ]<<endl;
            j++;
        }else{
            cout<<male[k]<<" "<<female[n/2 - 1 - k]<<endl;
            k++;
        }
        
    }    
    
    return 0;
}
```
