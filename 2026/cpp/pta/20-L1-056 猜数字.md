# L1-056 猜数字 (**分数 20**)

### 题目描述

一群人坐在一起，每人猜一个 100 以内的数，谁的数字最接近大家平均数的一半就赢。本题就要求你找出其中的赢家。

### 输入格式：

输入在第一行给出一个正整数 N (≤ 10<sup>4</sup>)。随后 N 行，每行给出一个玩家的名字（由不超过 8 个英文字母组成的字符串）和其猜的正整数 (≤ 100)。

### 输出格式：

在一行中顺序输出：大家平均数的一半（只输出整数部分）、赢家的名字，其间以空格分隔。题目保证赢家是唯一的。

### 输入样例 1:
```text
7
Bob 35
Amy 28
James 98
Alice 11
Jack 45
Smith 33
Chris 62
```
### 输出样例 1:
```text
22 Amy
```

## Code
```c
#include<iostream>
#include<vector>
#include<string>
#include<cmath>
using namespace std;

struct Player {
    string name;
    int num;  // 猜测的数字
};

int main(){
    int n;
    cin >> n;
    
    vector<Player> players(n);
    int sum = 0;
    
    // 读入数据
    for(int i = 0; i < n; i++) {
        cin >> players[i].name >> players[i].num;
        sum += players[i].num;
    }
    
    // 计算平均数的一半（整数部分）
    int half_avg = sum / n / 2;
    
    // 寻找最接近的赢家
    int min_diff = 101;  // 最大可能差值为100
    string winner;
    
    for(int i = 0; i < n; i++) {
        int diff = abs(players[i].num - half_avg);
        if(diff < min_diff) {
            min_diff = diff;
            winner = players[i].name;
        }
    }
    
    cout << half_avg << " " << winner << endl;
    
    return 0;
}
```
