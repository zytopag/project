# L1-003 个位数统计

**分数 15**

全屏浏览  切换布局

作者 陈越  单位 浙江大学


### 题目描述

给定一个 k 位整数 N = d<sub>k-1</sub>10<sup>k-1</sup> + ... + d<sub>1</sub>10<sup>1</sup> + d<sub>0</sub> (0 &le; d<sub>i</sub> &le; 9, i = 0, ..., k-1, d<sub>k-1</sub> > 0)，请编写程序统计每种不同的个位数字出现的次数。例如：给定 N = 100311，则有 2 个 0、3 个 1、和 1 个 3。


### 输入格式：

每个输入包含 1 个测试用例，即一个不超过 1000 位的正整数 N。


### 输出格式：

对 N 中每一种不同的个位数字，以 `D:M` 的格式在一行中输出该位数字 D 及其在 N 中出现的次数 M。要求按 D 的升序输出。


### 输入样例1:
```text
[ in ]
100311
```

### 输出样例1:

```text
[ out ]
0:2
1:3
3:1
```

## Code
```c
#include<iostream>
#include<string>
#include<map>
using namespace std;

int main(){

    string n;
    cin>>n;

    map<char,int>dig_count;
    for(char dig : n){
        dig_count[dig] += 1;
    }
    for(auto& pair : dig_count){
        cout<<pair.first<<":"<<pair.second<<endl;
    }

    return 0;
}
```
```cpp
#include<iostream>
#include<string>
#include<vector>
using namespace std;

int main(){

    string num;
    cin>>num;

    vector<int>count(10,0);
    for(char c : num){
        int dig = c - '0';
        count[dig] += 1;
    }
    int index = 0;
    for(int val : count){
        if(val){
            cout<<index<<":"<<val<<endl;
        }
        index++;
    }
    return 0;
}
```
