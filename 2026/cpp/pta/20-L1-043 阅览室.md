# L1-043 阅览室 (**分数 20**)

### 题目描述

天梯图书阅览室请你编写一个简单的图书借阅统计程序。当读者借书时，管理员输入书号并按下 **S** 键，程序开始计时；当读者还书时，管理员输入书号并按下 **E** 键，程序结束计时。书号为不超过 1000 的正整数。当管理员将 0 作为书号输入时，表示一天工作结束，你的程序应输出当天的读者借书次数和平均阅读时间。

注意：由于线路偶尔会有故障，可能出现不完整的记录，即只有 **S** 没有 **E**，或者只有 **E** 没有 **S** 的记录，系统应能自动忽略这种无效记录。另外，题目保证书号是书的唯一标识，同一本书在任何时间区间内只可能被一位读者借阅。

### 输入格式：

输入在第一行给出一个正整数 N (&le; 10)，随后给出 N 天的记录。每天的记录由若干次借阅操作组成，每次操作占一行，格式为：

`书号`([1,1000]内的整数) `键值`(`S`或`E`) `发生时间`(`hh:mm`，其中`hh`是[0,23]内的整数，`mm`是[0, 59]内整数)

其中：
- 书号为 [1, 1000] 内的整数
- 键值为 `S` 或 `E`
- 发生时间为 hh:mm 格式，其中 hh 是 [0, 23] 内的整数，mm 是 [0, 59] 内的整数

每一天的记录保证按时间递增的顺序给出。

### 输出格式：

对每天的记录，在一行中输出当天的读者借书次数和平均阅读时间（以分钟为单位的精确到个位的整数时间）。

### 输入样例 1:
```text
[ in ]
3
1 S 08:10
2 S 08:35
1 E 10:00
2 E 13:16
0 S 17:00
0 S 17:00
3 E 08:10
1 S 08:20
1 E 08:30
0 E 17:00
```

### 输出样例1:

```text
[ out ]
2 196
0 0
1 60
```

## Code
```cpp
#include<iostream>
#include<string>
#include<map>
using namespace std;

int cal_single_time(string Time){
    size_t pos = Time.find(':');
    string hourStr = Time.substr(0, pos);
    string minStr = Time.substr(pos + 1);
    int h = stoi(hourStr);
    int m = stoi(minStr);
    return (h * 60 + m);
}

int cal_time(string Start,string End){
    int star = cal_single_time(Start);
    int fin = cal_single_time(End);
    return (fin - star);
}

int main(){

    int n;
    cin>>n;

    for(int i = 0;i<n;i++){
        map<int,string>books;
        bool save[1001];
        fill(save, save + 1001, true);
        int total_time = 0;
        int count_book = 0;
        while(1){
            int num;
            char oper;
            string Time;
            cin>>num>>oper>>Time;
            if(num == 0) break;

            if(oper == 'S'){
                save[num] = false;
                books[num] = Time;
                //books.insert({num,Time})不行，因为如果    insert了map里有的键而不同的值，会插入失败，所以用books[num] = Time直接覆盖
            }else if((oper == 'E')&&(save[num]==false)){
                count_book++;
                total_time += cal_time(books[num],Time);
                save[num] = true;
                books.erase(num);
            }
        }
        if(count_book == 0){
            cout<<"0 0"<<endl;
        }else{
            //四舍五入
            double avg = (double)total_time / count_book;
            cout<<count_book<<" "<<(int)(avg + 0.5)<<endl;
        }
    }

    return 0;
}
```
