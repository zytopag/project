### 题目描述

本题要求你计算 A - B。不过麻烦的是，A 和 B 都是字符串——即从字符串 A 中把字符串 B 所包含的字符全删掉，剩下的字符组成的就是字符串 A - B。

---

## 输入格式：

输入在 2 行中先后给出字符串 A 和 B。两字符串的长度都不超过 10<sup>4</sup>，并且保证每个字符串都是由可见的 ASCII 码和空白字符组成，最后以换行符结束。

---

## 输出格式：

在一行中打印出 A - B 的结果字符串。

## 输入样例1：
```text
[ in ]
I love GPLT!  It's a fun game!
aeiou
```
### 输出样例1:
```text
[ out ]
I lv GPLT!  It's  fn gm!
```

## Code
```c
#include<iostream>
#include<string>
using namespace std;

int main(){

    string a,b;
    getline(cin,a);
    getline(cin,b);

    for(size_t i = 0;i<a.size();){
        if(b.find(a[i])!=-1){
            a.erase(i,1);
        }else{
            i++;
        }
    }
    cout<<a;
    return 0;
}
```
