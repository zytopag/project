# L1-039 古风排版 (**分数 20**)

### 题目描述

中国的古人写文字，是从右向左竖向排版的。本题就请你编写程序，把一段文字按古风排版。

### 输入格式：

输入在第一行给出一个正整数 N (< 100)，是每一列的字符数。第二行给出一个长度不超过 1000 的非空字符串，以回车结束。

### 输出格式：

按古风格式排版给定的字符串，每列 N 个字符（除了最后一列可能不足 N 个）。

### 输入样例 1:
```text
4
This is a test case
```
### 输出样例 1:
```text
asa T
st ih
e tsi
 ce s
```

## Code
```c
#include <iostream>
#include <string>
#include <stack>
#include <vector>
using namespace std;

int main() {
    int n;
    string s;
    
    cin >> n;
    cin.ignore();
    getline(cin, s);

    vector<string>rows;
    for(size_t i = 0;i<s.length();i+=n){
        string row = s.substr(i,n);
        while(row.size()<n){
            row += ' ';
        }
        rows.push_back(row);
    }

    for(int col = 0;col<n;col++){
        stack<char>stk;
        for(string& row : rows){
            stk.push(row[col]);
        }

        while(!stk.empty()){
            cout<<stk.top();
            stk.pop();
        }
        cout<<endl;
    }
    
    return 0;
}
//cin之后要接getline的话，中间要补一个cin.ignore()来接受cin之后缓冲区的\n(回车) again!!!
```
